# 参与

谢谢你愿意帮忙。总的参与指南在 [Vibes-college/vibes-college 的 CONTRIBUTING.md](https://github.com/Vibes-college/vibes-college/blob/main/CONTRIBUTING.md)，问题和建议也在那里提。

改这个仓库的代码：

- 大改动先开 issue，说清楚想改什么、为什么。
- 代码风格和开发方法跟着 Misskey，见 [CONTRIBUTING.misskey.md](CONTRIBUTING.misskey.md)。
- Misskey 本身的问题，请报给上游 [misskey-dev/misskey](https://github.com/misskey-dev/misskey)。
- 不要提交密钥、个人信息、视频，以及没有授权的图片和音乐。
- 你的贡献按 AGPL-3.0 授权。参与即表示你同意遵守[行为准则](CODE_OF_CONDUCT.md)。

## English

Thanks for helping. The general guide lives in [Vibes-college/vibes-college](https://github.com/Vibes-college/vibes-college/blob/main/CONTRIBUTING.md), and so do issues. For this repository: open an issue before big changes; follow Misskey's code style and workflow ([CONTRIBUTING.misskey.md](CONTRIBUTING.misskey.md)); report Misskey's own bugs upstream; never commit secrets, personal data, videos, or media you have no rights to. Contributions are licensed under the AGPL-3.0, and you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
