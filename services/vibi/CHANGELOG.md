# Mia on Mastra（试点）更新记录

## v0.4.1（2026-11-13）

- 等模型回话最多 60 秒（`REPLY_TIMEOUT_MS` 可改）。超时就放弃这一句，给学员回「我这边刚才卡住了，没来得及回你 😅 / 能再发一次吗？这次我马上看。」，后面排队的学员不再被一句卡死的调用堵住（11-12 测试站有一次挂了 809 秒）。超时的调用在用量日志记 `status=aborted`。
- 模型吐出坏掉的 JSON 时，把 `"messages"` 后面的几句话捞出来正常发，学员不会再看到 `{"messages": [...` 原文。

## v0.4.0（2026-11-12，局域网测试站）

- Vibi 多了四把查小程序的通用工具：listApps（有哪些小程序、能读哪些数据）、appSpec（一个小程序能答什么）、appCall（读这位学员在小程序里的数据）、recentActivity（最近几天每练完一组的一行摘要）。
- 不管以后有多少小程序，工具清单都是这四把，不变，所以固定开头照样能命中缓存。读之前社区先查授权（小程序 × 数据种类，现在默认只给 Vibi）。

## v0.3.2（2026-11-12）

- 每次回复带回这位学员的真实用量（命中、未命中、输出 token），包括上一句之后在后台跑完的观察和整理记忆的调用。社区按这个扣个人额度，不再按固定每句 ¥0.005 估。
- 用量按学员记账，不会记到下一位学员头上。

## v0.3.1（2026-11-12）

- Mia 改名 Vibi（名字和人设都来自社区的共用提示词，这里不用改）。记账时认得新的开头「You are Vibi, the AI on Vibes」，日志照旧记成 `source=mastra.mia`，旧开头也认得。

## v0.3.0（2026-11-11）

- 社区可以按学员把 Mia 交给这里：社区把学员新发的消息发来，这里回话，回复由社区发出去。
- 「现在几点、名字、问到的关卡」不再放进系统提示词，改成学员最后一条消息前面的一行方括号，固定开头整段都能命中缓存。
- 工作记忆规则写得更硬：同一轮里先存目标、考试、日期、分数、弱项等长期信息再回答。
- 观察记忆默认攒到约 20,000 token 才压缩一次（原来 7,000），压缩次数少、缓存断得少。
- 和社区之间用共享密钥（LOJO_TUTOR_MASTRA_SECRET），不再用管理员 token；每次调模型都打一行 `model usage source=mastra.…` 日志。
- 新增 `/migrate`：把现版 Mia 的笔记（档案、事实、聊天摘要）搬进工作记忆，可以重复跑，不删原来的笔记。

## v0.2.0（2026-11-11）

- 所有学习者共用一个 Mia：固定提示词里没有任何因人而异的内容，名字和「现在几点」放在后面。
- 回答语言跟着学习者这一句走（这条写在社区的共用提示词里，两边一样）。
- 工作记忆：考试日期这类信息改了就替换旧值，不再把旧值当现行信息留着。
- 新增 `tools/exam.mjs long`：60 句长对话（中间停 5.5 分钟），三个学习者同时跑，跟社区那边同一份剧本。
- Reflector 门槛可以用 `OM_REFLECT_TOKENS` 临时调低，只给短测试用；不设就是 Mastra 默认的 40000。

## v0.1.1（2026-11-11）

- 修：观察记忆的模型只写一处（Mastra 不许同时写两处），Observer 和 Reflector 照旧都用 deepseek-flash。

## v0.1.0（2026-11-11）

- 第一版，只在局域网测试站旁边跑，不碰正式站。
- 用了 Mastra 的四样：聊天记录、工作记忆（按学员存，不放进系统提示词）、观察式记忆（Observer / Reflector，固定用 deepseek-flash，攒到约 7,000 token 压缩一次，闲 5 分钟也压缩）、四个工具（进度卡、查聊天、查生词本、某关错因，都通过社区的管理员接口 lojo/tutor/pilot-tool 查）。
- 没用：向量（不装 pgvector、不调 embedding）、ee/ 企业功能、workflow。遥测关掉。
- 数据存在测试站数据库里单独的 mia_mastra schema。
- 每次调 DeepSeek（Mia 自己的、Observer 和 Reflector 的）都记一行到 data/usage.jsonl：命中、没命中、输出、耗时、花费。
