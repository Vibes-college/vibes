# 词汇线小程序 更新记录

## v0.1.0（2026-11-12，局域网测试站）

- 从社区搬出来，自己一个小程序：地址 `/apps/vocab/<站>`（如 `/apps/vocab/5.2`），自己上线、自己退回，不碰社区。要登录社区账号，和以前一样。
- 每一站拼对过、拼错待复习的词存在小程序自己的数据表里（`app_vocab`），社区里的旧记录搬过来，旧的先留着不删。两台设备同时练不会互相盖掉（合并改在小程序后台做）。
- 拼错的词加进生词本小程序，和以前一样。
- 新增只读接口（`/apps/vocab/api.json`）：9 站各自的进度和待复习的词、每答一个词的记录。Vibi 经过社区查授权后才能读。
- 旧地址 `/vocab/<站>` 永久跳到新地址，问号后面的参数一起带过去；闯关「去装备练一组」、补心都照旧。
